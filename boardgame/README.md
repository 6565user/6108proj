# Network Monopoly: Operator Edition

A board game that reinforces the networking concepts introduced in the morning lessons and Packet Tracer experiments. Players build router connections and complete packet delivery tasks to review IP subnets, gateways, routing, and access control through a simplified model of network operation.

## Suggested Use

1. Watch the short introduction for an overview of the activity.
2. Read the rulebook and watch the detailed gameplay animation to prepare for play.
3. Print and cut out the components, then prepare four player pieces and pens for recording resources and network links.
4. Play the game after the lessons and experiments, and discuss how the game relates to the networking concepts covered.

## Printing

Use **Board_Game_Printable_Components.pdf** for printing:

- **Page 1:** A3 landscape board.
- **Pages 2–7:** A4 portrait cards, player panels, and ACL markers.
- Print single-sided at **100% / actual size** and cut along the component borders.
- Keep the host answer panel separate from the question deck.
- Print additional ACL markers if needed. Player pieces must be supplied separately.

## Game at a Glance

- **Players:** 4
- **Starting resources:** 5 per player
- **Each turn:** Draw a movement card, move clockwise, and resolve the landing-space event.
- **Game end:** After each player completes 8 turns.
- **Winner:** The player with the most remaining resources. Tied players share the win.

Refer to the rulebook for the complete rules. The game simplifies network operation to help students consolidate their learning.
