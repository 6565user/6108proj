# Introduction to Computer Networking Workshop

## Overview

This repository contains the materials developed for our introductory computer networking workshop, designed for Year 1 junior college students with an interest in science and mathematics.

The workshop aims to introduce fundamental networking concepts through structured learning sessions, hands-on network simulations, and an interactive board game. It focuses on helping participants understand how devices communicate, how data packets are transmitted across networks, and how routers make forwarding decisions.

No prior knowledge of computer networking is required.

## Learning Objectives

By working through the workshop materials, participants are expected to develop an understanding of:

- Basic network topology and architecture, including nodes, links, paths, and hops.
- IPv4 addressing, subnet masks, and the role of the default gateway.
- Packet transmission, ARP, and hop-by-hop forwarding.
- Routing tables, next-hop selection, and static routing.
- Basic network configuration and troubleshooting using Cisco Packet Tracer.

## Repository Contents

This repository contains the following resources:

| Resource | Description |
|---|---|
| **Learning Session Slides** | Presentation slides introducing the fundamental networking concepts covered in the workshop. |
| **Learning Manuals** | Instructional materials and step-by-step guidance to support the learning sessions and practical activities. |
| **Packet Tracer Files** | Cisco Packet Tracer (`.pkt`) files for practising network configuration, examining packet transmission, and exploring routing behaviour. |
| **Board Game Materials** | Materials related to the networking board game, designed to reinforce networking concepts through interactive gameplay. |

## How to Use the Materials

1. **Review the learning materials:** Read the relevant manual and review the presentation slides to become familiar with the networking concepts.
2. **Complete the practical exercises:** Open the corresponding `.pkt` files using Cisco Packet Tracer and follow the instructions provided in the manuals.
3. **Explore the board game:** Refer to the available board game materials to understand the game mechanics and how they relate to the networking concepts introduced in the workshop.

For the best learning experience, participants are encouraged to follow the materials in the order presented in the learning sessions.

## Requirements

- **Cisco Packet Tracer:** Required to open and interact with the provided `.pkt` files.

Please ensure that the appropriate software is installed before starting the practical exercises.

## Intended Audience

These resources are intended for beginners who are interested in understanding the fundamentals of computer networking. They may also serve as supplementary learning materials for students who wish to explore basic networking concepts independently.
